# autofonce

**autofonce has moved.**

autofonce, a modern runner for GNU Autoconf testsuites, is now developed
and distributed as part of SuperBOL Studio:

* Sources: https://github.com/OCamlPro/superbol-studio-oss, in
  [`src/autofonce`](https://github.com/OCamlPro/superbol-studio-oss/tree/master/src/autofonce)
* Issues and pull requests: https://github.com/OCamlPro/superbol-studio-oss/issues

This repository is no longer maintained. Its history is kept for reference:
the last version of the sources is available at commit `97f0688`.
